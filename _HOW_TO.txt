NAV ANIMATION v2 -- fills the icon itself
=========================================
v1 grew a green pill behind the icon (same shape for all four). This
fills each icon's own outline instead: the flame fills like a flame, the
shield like a shield, and so on.

   cd C:\Users\onur1\Documents\solmates-web

   git commit -m "nav icons fill on tap"

FILE
  components/TabShell.tsx

HOW IT WORKS
A solid green copy of the same icon sits underneath the outline one. On
tap it scales up from the centre and fades in, so the green appears to
flood the icon from inside its own shape. Fades back after ~0.34s. The
press dip and spring-back are unchanged.

Want the fill to STAY on whichever tab you're currently on, instead of
fading out? That's a small change and it looks good -- just say so.
