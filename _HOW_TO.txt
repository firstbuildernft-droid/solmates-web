ADMIN: all-users list with data + activity score
=================================================
Adds a full user list to your existing /admin panel: everyone signed up,
their profile data, and an activity score. No migration.

SECURITY: the admin panel is already locked to your account (ADMIN_EMAILS)
and returns 404 to anyone else -- that's stronger than a password. Make
sure your email is in the ADMIN_EMAILS env var in Vercel (it already is if
/admin works for you now).

FILES
  lib/allUsers.ts        <- NEW (pulls all users + activity)
  app/admin/page.tsx     <- REPLACES (adds the users table)

WHAT YOU GET (visit /admin)
A table of every signed-up user, sorted by activity score, showing:
name, gender, age, city, join date, face-verified, wallet-verified, SOL
balance, photo count, likes given, likes received, matches, messages, and
a score. Users who haven't finished onboarding show "(incomplete)".

The score = likesGiven + likesReceived + matches*4 + messages*2. Tune the
weights in lib/allUsers.ts if you want.
