WALLET LOGOS
============
The picker now accepts png, svg, webp or jpg, so whatever format your
files are in will work.

STEP 1 -- copy your three logos in, renamed, keeping their extension.
Paste this whole block into PowerShell:

$dest = "C:\Users\onur1\Documents\solmates-web\public\wallets"
New-Item -ItemType Directory -Force -Path $dest | Out-Null
$map = @{ "phantom_logo" = "phantom"; "solflare_logo" = "solflare"; "trust_logo" = "trust" }
foreach ($k in $map.Keys) {
  $src = Get-ChildItem "C:\Users\onur1\OneDrive\Masaüstü\$k.*" -ErrorAction SilentlyContinue | Select-Object -First 1
  if ($src) {
    Copy-Item $src.FullName "$dest\$($map[$k])$($src.Extension)" -Force
    Write-Host "copied $($map[$k])$($src.Extension)"
  } else {
    Write-Host "NOT FOUND: $k"
  }
}

It prints what it copied. If any say NOT FOUND, the file isn't on the
Desktop under that name -- tell me the real name.

   Copy-Item "C:\Users\onur1\OneDrive\Masaüstü\logos\*" "C:\Users\onur1\Documents\solmates-web" -Recurse -Force
