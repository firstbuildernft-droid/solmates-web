IMAGE MODERATION
================

Blocks harmful photos (nudity, gore, violence, weapons, hate symbols,
hard drugs) on upload, BEFORE they're stored. Allows normal dating photos
including swimwear / shirtless / gym pics.

NO migration this time. No new env vars -- uses the AWS keys you already
have.

1. Copy files in (adjust path if needed):

   Copy-Item "C:\Users\onur1\OneDrive\Masaüstü\moderation\*" "C:\Users\onur1\Documents\solmates-web" -Recurse -Force
   Remove-Item "C:\Users\onur1\Documents\solmates-web\_HOW_TO.txt" -ErrorAction SilentlyContinue

2. Push to deploy:

   cd C:\Users\onur1\Documents\solmates-web
   git add .
   git commit -m "image moderation"
   git push

   Watch Vercel go green.

FILES
   lib/moderation.ts                    <- NEW (the Rekognition check)
   lib/photos.ts                        <- REPLACES (uploads via server now)
   app/api/photos/upload/route.ts       <- NEW (moderate-then-store)

HOW IT WORKS
- Browser shrinks the photo, sends it to the server.
- Server runs Rekognition DetectModerationLabels.
- Harmful -> rejected, user sees "That photo can't be used here",
  nothing is stored.
- Clean -> uploaded and saved as before.
- If Rekognition is ever DOWN, uploads are allowed through (fail-open) so
  an outage doesn't block onboarding. Logged in Vercel.

TEST
- Normal selfie / beach photo -> uploads fine.
- To test a block without anything nasty: Google an image labelled as
  "graphic violence" news photo, or any obvious weapon-brandishing image,
  and try to upload it -> should be rejected. (You don't need to test with
  anything truly disturbing -- a photo of a handgun pointed at camera
  trips "Weapons".)

COST: $0 for your first 5,000 uploads/month (free tier, 12 months), then
about $1 per 1,000 photos. Same Rekognition you already use.
