-------------------------------------------------------------------------
Supabase -> Authentication -> Emails -> "Magic Link" template.
The default template sends a LINK. We need it to send the CODE.
Replace the template body with something like:

    <h2>Your Solmates code</h2>
    <p>Enter this code to sign in:</p>
    <p style="font-size:28px;font-weight:bold;letter-spacing:4px">{{ .Token }}</p>
    <p>It expires in a few minutes.</p>

The key part is {{ .Token }} -- that's the 6-digit code. (The old
template used {{ .ConfirmationURL }} -- the link. Remove that.)
