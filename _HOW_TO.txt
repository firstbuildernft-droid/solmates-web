SETTINGS TAB
============

New Settings screen (gear icon, top-right of Profile) with: pause profile,
blocked users + unblock, distance unit, notification toggles, language
(English; more later), terms/privacy links, sign out, and DELETE ACCOUNT
(App Store requirement).

1. Run migration: Supabase -> SQL Editor -> paste 0009_settings.sql -> Run.

2. Copy files in:

   Copy-Item "C:\Users\onur1\OneDrive\Masaüstü\settings\*" "C:\Users\onur1\Documents\solmates-web" -Recurse -Force
   Remove-Item "C:\Users\onur1\Documents\solmates-web\_HOW_TO.txt" -ErrorAction SilentlyContinue

3. Push:

   cd C:\Users\onur1\Documents\solmates-web
   git add .
   git commit -m "settings tab"
   git push

- Profile tab -> gear icon (top right) -> Settings.
