SEARCH FILTERS v2 -- sliders, no typing
=======================================
Replaces the number boxes (which clamped as you typed, so you couldn't
enter anything) with drag sliders.

1. RUN THE MIGRATION if you haven't already:
   Supabase -> SQL Editor -> paste 0012_filters.sql -> Run.
   (Safe to run again if you already did -- it's all create-or-replace
   and "add column if not exists".)

                                          deployed v1 -- included so this

WHAT'S DIFFERENT
- Age: one track, TWO handles. Drag them to set the range. 18 to 70,
  where 70 means "70 and up". Both at the ends reads "Any".
- Maximum distance: one handle, 1 to 250 km. All the way right = "Anywhere".
- Minimum wallet balance: one handle, 0 to 100 SOL. All the way left = "Any".
- Verified only: still a toggle (it's on/off, nothing to slide).
- The value shows on the right of each label and updates as you drag.
