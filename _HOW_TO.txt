SMOOTH TABS v2 -- state switching, no router (the real fix)
===========================================================
The last version still used the router to switch tabs, which caused the
lag + flash. This version switches tabs with pure STATE -- instant, no
navigation, no flash. The tab bar now lives inside the shell.

Requires the smooth.zip files already in place (tabs_*Content.tsx). If you
deployed smooth.zip, you have them. This just replaces 2 files on top.

   cd C:\Users\onur1\Documents\solmates-web
